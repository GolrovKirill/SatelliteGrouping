# 🛰️ Спутники и группировки

Данный проект представляет собой программную реализацию задачи динамической группировки космических аппаратов (КА) на основе временных интервалов связи. Глобальное время разбивается на такты по 10 минут, для каждого такта строятся компоненты связности активных связей — группировки. Результат визуализируется в виде графика Ганта, графа связей и матрицы интервалов.

---

## 🌟 Основные возможности

*   **Интуитивный интерфейс**: Удобная форма с крупными элементами управления, графиком Ганта и графом связей.
*   **Пошаговая визуализация**: Просмотр группировок для любого такта с помощью трекбара и кнопок «◀ ▶».
*   **Точная временная диаграмма**: Цветные прямоугольники соответствуют реальным интервалам связи, белые — периодам изоляции спутников.
*   **Граф связей**: Для выбранного такта показывает активные каналы и раскраску вершин по группам.
*   **Матрица интервалов**: Все прямые интервалы между каждой парой КА в удобной таблице.
*   **Загрузка своих данных**: Поддержка текстовых файлов простого формата.
*   **Встроенный пример**: 5 спутников, 3 интервала связи, глобальное время 30 минут.
